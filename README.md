# User_Management_Application
User Management System with Python | SQLite | Multi-Frame UI (Using TTKBootstrap)

🚀 I recently worked on a fully Object-Oriented User Management System project designed with a three-layer architecture and uses SQLite3 for data storage. The project features a multi-frame UI, created with ttkbootstrap to provide a visually appealing and user-friendly experience.

🔹 Key Features:
✅ User Registration: Data is stored in the database, and passwords are hashed for enhanced security.
✅ User Login: Includes a Remember Me feature for user convenience.
✅ Home Page: Displays the Manage Users button only for the admin.
✅ User Management Page:
🔸 Supports Pagination (10 users per page)
🔸 Allows changing user status (Active, Pending, Deactive)
🔸 Enables changing user roles (Admin, Default User)
🔸 New users are initially Pending until the admin sets them to Active.
